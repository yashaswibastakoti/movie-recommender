# Content-based movie recommender
A content-based movie recommendation system using movies, ratings, and tags datasets.
This project generates personalized movie suggestions based on the content features of movies and user input preferences.

## Overview
The system uses content-based filtering, where recommendations are based on similarities in movie metadata such as genres, tags, and movie titles. By combining data from multiple sources, the system identifies movies that align closely with a user's interests.

## Features:
1) Content-based Filtering:
Recommends movies by analyzing content similarities (genres, tags, descriptions).

2) Multiple Datasets used:
- Movies dataset: movie titles and genres
- Ratings dataset: user movie ratings
- Tags dataset: user-provided labels for movies
  
3) Dataset Explroation:
Includes analysis to uncover patterns, trends, and insights into user preferences and movie characteristics.

- Distribution of ratings
- Top-rated and most-rated movies
- Most common gernes
- Top movie tags


## Input User Preferences: 
Users can input a movie title to get personalized recommendations based on content similarity.

## Future Enhancements
